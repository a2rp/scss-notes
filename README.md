# SCSS Study Notes

This repository is my personal set of SCSS study notes. I keep the concepts and examples I use while learning and working with Sass so I can revisit how a style is written, compiled, and organized. These notes explain the choices in my own words and keep small examples close to the ideas they demonstrate.

## Scope

The notes focus on SCSS, the CSS-like syntax of Sass, and the current Sass module system. They cover variables, nesting, mixins, functions, data structures, responsive styles, design tokens, compilation, source maps, and maintainable stylesheet architecture. Examples are written so they can be compiled into ordinary CSS and tested in a browser.

The notes prefer @use and @forward for Sass modules. The older Sass @import rule is included only when discussing existing code and migration.

## How these notes are organized

The first 15 chapters move from SCSS foundations to real stylesheet organization and maintenance. Each topic chapter includes explanations, code samples, review questions, and bordered links to the previous and next chapter. Chapter 98 collects all code samples, and Chapter 99 brings the review questions together with answers.

## Learning in practice

I use these notes while changing real stylesheets. I compile small examples, inspect the CSS output, and check the result in a browser. When a Sass feature generates CSS, the notes describe both the Sass source and the output so the compiler's role stays clear. I refine the examples as I learn better ways to organize styles.
