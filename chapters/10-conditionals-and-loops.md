## What I am learning here

Sass flow control emits CSS based on compile-time values. @if chooses a branch, and @each, @for, and @while repeat a block. These rules can generate repetitive utilities, but they can also produce large stylesheets that are hard to inspect.

## Generate a deliberate spacing scale

~~~scss
$steps: (
  "sm": 0.5rem,
  "md": 1rem,
  "lg": 1.5rem
);

@each $name, $value in $steps {
  .gap-#{$name} {
    gap: $value;
  }
}
~~~

This map keeps the supported values explicit. The resulting selectors are compile-time output. For a small component, a mixin or direct declarations may be easier to maintain than generated utility classes.

A conditional can validate a configuration value or choose a small compile-time style:

~~~scss
$mode: "dark";

@if $mode == "dark" {
  .surface {
    color: #ffffff;
    background: #202020;
  }
} @else {
  .surface {
    color: #202020;
    background: #ffffff;
  }
}
~~~

Flow control is not browser logic. Sass decides which rules to emit before the page loads. Keep loops bounded, avoid generating classes no one uses, and check the compiled file when a loop or condition changes.
